FORMS / EMAIL DELIVERY

All forms continue posting to:

- /process-form.php

The shared processor still uses the existing secure configuration, Cloudflare Turnstile validation, and ZeptoMail delivery settings.

Form routing was also tightened so each form returns to the correct section on validation errors, while successful paid-campaign submissions go to their matching request-received page under /offers/.

The roofing ad form now receives its own roofing email subject/heading and includes the selected roofing concern in the email. Organic roofing forms also include the selected roofing concern.

IMPORTANT SERVER REQUIREMENT

process-form.php uses PHP cURL for both Cloudflare Turnstile verification and ZeptoMail. The production PHP environment must have the cURL extension enabled. The original project already depended on this extension; the updated processor now fails gracefully instead of throwing a fatal error when it is unavailable.

CONFIGURATION

The config/secure_env.php file in this package is the same configuration that was present in the project supplied in this chat. If the live server has newer or environment-specific credentials, preserve the live version before replacing the project.
